## 📖 Sobre o Projeto
O **ClimaTempoReal** é uma aplicação desenvolvida para consultar e exibir as condições climáticas e a previsão do tempo de diversas cidades em tempo real. O objetivo do projeto é fornecer uma interface simples e intuitiva para que o usuário possa verificar informações como temperatura atual, sensação térmica, umidade e velocidade do vento utilizando dados de uma API externa de clima.

## ✨ Funcionalidades
- [x] Busca de clima por nome da cidade.
- [x] Exibição da temperatura atual, mínima e máxima.
- [x] Detalhes adicionais: umidade do ar, velocidade do vento e sensação térmica.

## 🚀 Tecnologias Utilizadas

**Back-end / Integração:**
- Java 
- Integração com API de Clima ([WeatherAPI](https://www.weatherapi.com/))
